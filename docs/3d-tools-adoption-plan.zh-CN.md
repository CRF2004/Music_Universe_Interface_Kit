> 更新：2026-10-05

> 来源与能力核对：[3D 工具研究](research/3d-tools-landscape-2026-10-02.zh-CN.md)

## 要得到什么

让创作者更容易摆放场景、改动音乐事件，并用现成工具减少模型、动画和特效的制作时间。所有结果进入同一份 MusicWorldProject，能够保存、重新打开和稳定重播。

当前阶段仍是 Phase 2：可重复、可编辑的完整创作流程。世界生成与面向创作者的 AI 服务在 Phase 3 评估。各项分别交付和验收。

## A：先让现有编辑顺手、安全

**用户结果：**改错可以退回；拖动一个地标后，画面、碰撞和保存结果一致。

**推进的阶段门槛：**创作者通过界面编辑、保存、重新打开和导出项目。

**最小完整交付：**

1. A1 将 Archive X/Z 和已有 Cue 时间修改统一为可验证事务。一次应用或完整拖动对应一条历史记录；无变化和无效输入不新增历史。
2. A1 明确新修改清除重做分支、切换/导入项目隔离历史、保存失败保留内存稿、撤销/重做触发自动保存。刷新后恢复项目；跨刷新编辑历史暂不持久化。
3. A2 使用受控的 Drei 操作柄，仅开放 Archive X/Z 移动。拖动时提供临时预览，结束时提交项目；取消或失去编辑状态时恢复提交前状态。摄像机和角色输入在编辑期间有明确协调。
4. A2 保留带标签的坐标输入和键盘操作入口；旋转、缩放、多选及其他物体编辑在后续独立设计。
5. A3 从默认项目已有动作中选择一种有明确价值的类型，先开放少量参数。编码前列出字段、范围和错误提示；所有入口复用项目校验与事务，不允许任意 JSON 绕过验证。

**验收证据：**

- 事务测试覆盖撤销、重做、新分支、取消、无效输入和项目切换；数据与默认模板保持独立。
- 浏览器完成修改 → 撤销 → 重做 → 自动保存 → 刷新 → 导出 → 再导入；位置、碰撞与音乐事件保持一致。
- 播放中编辑、前后跳转、自然结束及重播均重建正确状态；拖动中断能恢复。
- 键盘、焦点、可读标签、窄屏编辑布局及减少效果模式通过检查。
- 执行 npm test、npm run lint、npm run build；Chrome/Edge 创作者旅程及恢复回归通过，保留截图与结果。

**性能、权利与回退：**优先复用现有依赖，检查编辑器关闭时的加载成本与监听器清理。A 阶段不新增外部资产。操作柄不满足质量要求时继续使用可撤销的坐标编辑。

A1/A2 的实现范围、截图、构建成本和复测限制见[拖拽编辑验收记录](validation/archive-drag-editing-2026-10-02.md)。编辑历史最多 100 条，刷新后清空；已提交的项目继续自动保存。A3 开放已有环境动作的天空/地面颜色、雨量和光晕参数；Phase 2 整体验收仍待完成。

A3 的保存、撤销重做、时间跳转、画面和浏览器证据见[环境参数验收记录](validation/cue-environment-editing-2026-10-02.md)。A4 结果如下。

A4 首次记录见[创作流程验收](validation/creator-workflow-acceptance-2026-10-02.md)，阻塞修复见[歌曲恢复验收](validation/project-audio-recovery-2026-10-02.md)：Chrome / Edge 各 125 项真实歌曲完整流程检查和 8 项故障恢复检查通过。歌曲信息随项目保存，刷新后引导选择并验证原文件。A4 工程门槛通过；Phase 2 整体仍需人类创作者观察。B1 的参考图、账号与支出上限明确后再执行。

## B：用一项实际需求比较制作工具

**工程结果：**找到更省人工、适合网页且视觉一致的资产制作方法。

**阶段关系：**A4 后，为已可编辑的 Memory Journey 做独立的资产制作评估；采纳结果经正常资产审核。面向创作者的生成服务属于 Phase 3。

**B1 最小实验：**

- 选择一个现有重点道具和一张有生成使用权的参考图，固定风格、尺寸与面数预算。
- 本轮 DMX Tripo P1 与 Hyper3D 各成功生成 1 个，合计最多 ¥10；禁止自动重试付费提交。失败与无任务编号的网络中断先核查，记录实际账单与生成用量。
- DMX 使用独立离线实验请求；现有直连 Tripo CLI 保留。Meshy 由用户用免费额度生成并返回 GLB，记录实际模型版本。P1、P2 与 Rodin 的证据分别记账。
- 同时比较造型、分件、材质、碰撞制作难度、失败次数、优化后体积和场景截图。
- 决策结果为采用一种、保留两种不同用途，或继续现有资产。任何结果都要有证据；完整记录失败样本。

**B2 最小实验：**

- 在“角色互动动作”和“记忆恢复视觉反馈”中选一个具体问题，每轮只处理一个。
- 动作候选使用 Quaternius，核对包版本、所需动作及骨骼适配；特效候选使用 Wawa VFX，检查依赖、时钟与可重建性。
- 保留现有角色控制与旅程规则。通过暂停、跳转、重播和减少效果模式验证后，决定是否采纳。

**验收证据：**模型报告、对照截图、人工整理时间、费用与权利记录；采纳资产通过 assets:validate、assets:build 和构建。角色/特效变化另有真实浏览器生命周期和视觉证据。

**性能与回退：**遵守现有模型、纹理、总资产和浏览器性能预算，记录生产包增量及目标设备结果。生成失败、绑定失败或粒子表现不稳定时使用原资产和原反馈。新工具的服务条款与输出资产权利在实际制作时核验。

## C：独立小空间实验，正式接入留待 Phase 3

用户于 2026-10-02 明确安排 B1 与一个 Marble 小空间，现金上限 ¥0，只使用现有免费额度。已准备项目自制传送门参考图与同图参数；Tripo API 密钥有效、余额为 0。Marble 免费档的生成和观看可先评估，导出列于付费档，遇到费用入口即停。账号与样本准备好后继续实测；完整状态、指标和官方入口见[免费额度实验记录](validation/3d-tool-pilots-2026-10-02.md)。本次独立小样保持正式产品阶段和运行时依赖，HY-World 对比留待后续。

**用户结果：**一个生成的记忆空间可以在网页中探索，重点地标仍能编辑和互动。

**最小实验：**选择一个明确边界的小空间，先检查 Marble 导出，再在独立预览中验证普通网格与 Spark 高斯显示。HY-World 作为对比候选；工具运行环境和费用超出已定上限时记录限制并停止。

每个服务最多生成 2 个场景；开始前确定尺寸、输入权利、账号、计算成本和总支出上限。暂不部署创作者服务、云端任务系统或公开分享。

**验收证据：**

- 保存完整输出、版本与来源，测量冷加载、下载体积、代表性视角帧率及内存。
- 检查近景破损、遮挡、碰撞、光照变化，以及普通可编辑地标与生成背景的组合效果。
- 普通网格先走现有资产管线；高斯格式另列资产类型、加载失败、清理和预算方案，再决定是否扩展项目格式。
- 项目保存/导出后的资源路径稳定；相同音乐时间能够重建相同互动状态。
- 通过实验后提交采纳或延期结论及正式接入范围。高斯效果不达标时保留普通网格或原模板。

SuperSplat 可作为外部高斯清理工具评估。Music Universe 的支持设备和 WebGL 2 基线继续按现有性能文档执行。

| 候选 | 计划角色 | 触发条件 |

| BVHEcctrl | 碰撞/加载性能对照 | 目标设备证据表明现有物理开销阻塞体验；先确认动态刚体需求 |

| ARDY | 离线特色动作生成参考 | 现成动画无法表达已接受的动作需求 |

| WorldClaw / Buffalo / Scenethesis | 布局、分件编辑和空间检查的方法参考 | Phase 3 设计；可运行实现开放后再评估工具采纳 |

## 每轮的决策规则

每轮只解决一个明确问题，保留现有可运行方案。开始前填写工作流要求的结果、阶段门槛、范围、验收、性能/无障碍/权利影响与回退路径。

工具进入产品须证明收益，并计算运行包、维护、许可和人工整理成本。服务密钥留在本地制作工具或未来后端，输出落为稳定文件。研究页面和最新版本号在实验开始时复核。

本计划的预算和次数限定各轮实验。2026-10-03 用户将 DMX 本轮现金上限调整为 ¥10，各生成 1 个；Meshy 使用现有免费额度，Marble 只评估付费价值，尚未授权购买。初始免费准备保留在 10 月 2 日记录，当前权限与样例证据见[更新实验记录](validation/3d-tool-pilots-2026-10-03.md)。
