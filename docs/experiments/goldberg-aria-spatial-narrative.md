# Goldberg Aria Spatial Narrative Experiment

A vertical slice experiment for Music Universe.

Pipeline:

```
Music timeline
  -> narrative cues
  -> world state changes
  -> camera / environment / interaction events
```

## World Bible

Core metaphor: a small planet that stores memories as light and opens a departure gate through listening.

Player role: the listener who completes the memory cycle.

## Chapters

- Arrival: pale daylight and first memory
- Awakening: environment begins responding
- Memory Garden: hidden zone opens
- Reflection: world becomes quieter
- Release: stars and departure gate appear
- Return: transformed planet remains

## Evaluation

This experiment tests whether music-driven spatial narrative creates more value than passive visualization before integrating external world generators.
