# 先打通：选模板和资产，搭出完整世界

日期：2026-10-18。用户明确选择这一方向作为当前优先事项。
状态：第一轮搭建界面与项目数据路径已实现，等待产品体验验收。包含记忆旅程模板与已审核的离场门。美术样片精修后增加原创花园归途拱门，当前共三款门；其他必需角色在普通搭建模板中沿用原有选择。

## 要交付的结果

创作者选一个模板，选用兼容资产，得到一个能进入、能完成、能保存和重新打开的音乐世界。音乐分段和 BPM 留作可选的精细修改。

本轮推进 Phase 3 的“推荐和选择资产 → 创作者确认 → 编译成统一项目 → 预览”路径，同时复用已验收的 Phase 2 项目保存能力。

## 第一轮最小闭环

**选记忆旅程 → 选兼容资产 → 创建完整项目 → 进入世界预览 → 保存/导出 → 再打开。**

1. **模板保底完整。** 首轮只用现有记忆旅程；引导、记忆互动、离场条件和音乐生命周期沿用验收结果。无需用户先填写 BPM 或编辑时间线。
2. **资产选择有边界。** 从现有已审核资产开始，列明名称、用途、预览、作者和许可。模板必需角色保持完整；只有具备兼容模型、尺寸和碰撞契约的槽位才允许替换。缺少替代款时明确展示当前可用项。
3. **选择写入项目。** 增加必要的、受校验的资产/布局声明，统一驱动视觉和碰撞。模板创建、手动选择和后续 AI 推荐共用这条路径。避免只换画面、保存后丢失或碰撞仍沿用旧模型。
4. **创建前检查。** 检查角色齐全、资源可解析、许可记录存在、尺寸/碰撞配置可用、关键互动可达。失败保留已有项目，指出具体槽位和修复动作。
5. **预览后保留结果。** 模型、位置、互动和结尾经过自动保存、刷新、JSON 导出再导入仍一致。资源失败保留明确提示和兼容的现有模板回退。

首次界面遵循少量步骤：模板、资产、预览。已有音乐编辑与高级参数后置；保留现有工作，后续根据实际搭建界面安排收纳。

## 验收证据

- 单元测试：目录/角色约束、项目生成、无效选择保护、保存回读一致。
- 浏览器：选择 → 创建 → 预览 → 完成旅程 → 保存 → 刷新/导入；确认实际显示和碰撞对应所选资源。
- 资源失败：缺失模型、错误引用和不可用配置有可操作的提示；已有项目保持有效。
- 视觉检查：开场、档案馆互动和结尾，模型比例、落地、遮挡和通路可用。
- 键盘焦点、可读标签、小窗口和减少效果模式。
- 按代码/资产改动执行仓库验证矩阵，记录构建体积与浏览器结果；新增资产另做授权、资源校验和目标设备检查。

## 第一轮实现契约

- 项目编辑器顶部提供“搭建一个音乐世界”：模板、世界名称、资产、创建并预览。
- 引导员、终端和档案馆各有一款已审核模型；离场门可选 Kenney 空间站门或项目自制环形门。离场门提供按需加载的独立模型预览。
- `scene.objects[].appearance.assetId` 是受校验的可选模型引用，必须匹配物体类型和 `project.assets` 内的模型/许可记录。显示、尺寸和碰撞共用已审核配置。
- 创建前解析整个模板的资源/许可记录，下载四个主要模型并核对体积和 SHA-256。检查最多 15 秒，可取消。音频及其他时间线地标继续使用原有加载/回退路径；此处未逐个下载它们验证。
- 创建生成独立项目，保留旧草稿；默认布局、互动条件、时间线、球形地面和结尾沿用模板。模型选择由导入导出和本地保存保留。
- 预览失败显示提示；创建检查失败保留当前项目并支持重试。切换项目或关闭编辑器会取消未完成的创建。
- 无新增模型、贴图、依赖、生成费用或托管服务。首轮未开放任意模型导入、通用摆放、多模板或所有地标资源的自由替换。

项目仍使用 v2，新增字段为可选；旧项目继续可读。旧版程序可能忽略此模型引用并显示默认模型，因此含资产选择的导出应由支持该字段的当前版本打开。跨旧版本重现资产选择不在本轮承诺内。

验证结果见[本轮验收记录](validation/world-assembly-2026-10-18.md)。产品体验验收与目标设备性能校准仍需后续完成。
