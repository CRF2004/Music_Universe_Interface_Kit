# Creator Workflow

Music Universe supports three creation paths:

## 1. AI Generation

User uploads music:

```
MP3
 -> music analysis
 -> world bible
 -> narrative timeline
 -> generated planet
```

## 2. Template Editing

Users can start from reusable assets:

- planets
- environments
- weather effects
- vegetation
- water
- lighting presets
- interaction modules

## 3. Remix Existing Worlds

A published planet can become a remixable foundation.

```
Original World
      |
      v
Remix
      |
      v
New Music Experience
```

The goal is reducing generation cost while increasing creative diversity.
