# Archive 可撤销拖拽：实现与验收

> 日期：2026-10-02
> Phase 2；工具采纳计划 A1/A2

## 交付范围

创作者打开 Project Editor，选择 **Drag in world**，拖动红色或蓝色箭头修改 Archive 的 X/Z。松手提交一次修改并自动保存。Undo / Redo 按钮与 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl/Cmd+Y 支持撤销和重做；文本框保留自身的快捷键行为。坐标输入继续可用。

Archive 坐标和已有 Cue 时间共用经过项目校验的事务。每次拖动只增加一条历史记录，最多保存 100 条；新修改清除重做分支，切换、导入和重置项目清空历史。刷新恢复已保存项目，编辑历史只保留在当前会话。

拖动过程只预览画面位置，提交后更新项目和碰撞。Escape、窗口失焦、页面隐藏和 pointercancel 取消未完成的拖动；取消后松手不会误提交。拖拽模式使用固定俯视镜头，暂停物理和角色移动，离开后恢复镜头。编辑期间暂停场景互动，音乐继续驱动时间线。

当前阶段门槛：通过界面编辑、保存、重新打开和导出同一份 MusicWorldProject。范围只含 Archive X/Z、现有 Cue 时间及其撤销重做。动作参数检查器、多选、旋转、缩放、其他物体和持久化历史留待后续。

## 成本与限制

复用已安装的 Drei PivotControls，未添加依赖或外部资产。编辑监听器随面板关闭清理；操作柄仅在拖拽模式挂载。坐标编辑提供键盘替代路径。

当前生产构建：ExperienceRoot 86.83 kB / gzip 24.76 kB；PhysicsWorld 62.05 / 19.03 kB；Three React 293.18 / 92.01 kB；Three runtime 732.50 / 189.78 kB；Rapier 2260.68 / 838.07 kB。工作树同时含先前的项目格式和创作流程实现，这些数字代表整个当前状态，不能全部归因于拖拽功能。
