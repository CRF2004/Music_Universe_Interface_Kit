# 第三轮：花园归途门与配乐准备

- 用户结果：离场门融入花园、交谈有更自然的反馈；给出可自行下载的配乐候选。
- 当前阶段门槛：Phase 3 模板和资产结果的展示质量。
- 最小闭环：原创木质花拱门 → 既有正式管线和项目资产选择 → 音乐末段亮起 → 可离场并重播。
- 范围外：音乐编辑器扩展、新故事、付费生成、平台改造、自动下载/接入未验收音乐、发布。
- 验收：实际画面、开门前/开门后/结尾、seek/replay、行走路线、浏览器交谈；单元/类型/资产/生产构建。
- 性能/无障碍/权利：原创 MIT 门模型、同一无碰撞通行契约、温和暖光；轻量模式静态反馈；原草稿数据保留。配乐仅核对官方候选，用户下载后单独接入。

## 实现与边界

新增原创 `garden-arbor`，由同一生成脚本与正式 manifest 构建。门采用木柱、藤叶、花朵与奶油色牌子，沿用 3.4 m 高度归一化与可直接穿行的无碰撞契约。材质配置关闭该模型的整体现成门发光，花园美术套件以静态暖光响应 charging/open/afterglow；状态来自既有音乐时间线，seek/replay 会重建。额外科幻门序列与重复霓虹路径在花园套件中收起，默认世界保留原行为。

守园人在交谈时增加小幅点头，呼吸位移减弱。轻量模式保持静态。当前模型仍无分肢绑定、手势或口型，不将小幅整体动作称为完整人物表演。

旧样片的环形门与上一轮人物一样，复制为新草稿升级；其他手工编辑与原草稿数据保留。普通搭建器的已审核门选项现在有三款，并修正了新选择需要追加正式许可引用的通用逻辑。

配乐准备中修正本地曲目恢复：刷新后需重新选择原文件，进入按钮不再把演示曲当成本地曲目载入；封面曲名随实际项目歌曲变化。配乐候选仅在 [初选记录](../echo-garden-music-shortlist.md) 中，没有下载或导入新配乐，当前 demo 仍用原已授权演示曲。

## 体积与性能观察
