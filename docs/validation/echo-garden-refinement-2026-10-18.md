# 回声花园第二轮：人物、道具与对话精修

用户已授权继续精修。此记录沿用第一轮的世界、故事和美术套件。

- 用户结果：在实际可玩场景中统一人物与道具，守园人交谈时可清楚看到人物与文案。
- 当前阶段门槛：Phase 3 模板/资产结果达到值得展示、可继续编辑和保存的体验质量。
- 最小闭环：新园丁与留声柜 → 正式资产管线 → 同一项目格式 → 近景交谈 → 返回探索 → 完成旅程。
- 范围外：新增故事、音乐编辑器、角色绑定平台、付费生成、部署发布、逐件布景编辑器。
- 验收：实际模型加载、对话构图、键盘焦点、完整互动/时间线、真实 WASD 路线、项目回读；单元测试、类型检查、生产与资产构建。
- 性能/无障碍/权利：两个原创 MIT 模型，沿用既有碰撞包络；对话镜头支持轻量模式的直接切换；原有关闭、Escape、焦点限制与恢复继续有效。

## 已制作

1. 原创 `garden-keeper`：草帽、陶土色上衣、青绿围裙、口袋和面部细节。朝向匹配既有 NPC 包装，渲染高度 1.7 m，沿用现有胶囊碰撞。
2. 原创 `garden-listening-cabinet`：木腿、奶油色柜面、唱片、唱针和青绿听筒。渲染高度 1.75 m，处于既有终端碰撞包络内。
3. 窗边花箱、近景盆栽与长椅，合并进既有布景的 13 个材质批次。主路线留空。
4. 美术套件保存守园人对话的目标、镜头位置和视角。近景展示人物，文案靠右；对话中隐藏路标与工具，关闭后返回原来的探索方向。轻量模式直接切换，不做镜头滑动。
5. 旧样片通过 `?study=coastal` 打开时，将旧的宇航员/终端选择复制到一个新草稿并替换为新人物/道具。旧草稿数据保留；标题、歌曲、工坊位置与其他编辑保持。已精修的草稿刷新不再重复复制。共享花园布景资产会更新，因此旧草稿的数据保留不等于冻结旧渲染器或所有旧画面。

制作脚本仍为 `scripts/generate-echo-garden.mjs`。新资产来源、许可快照与优化设置已入 manifest，未使用参考站资产或付费生成。

- `npm test`：120 项通过，含旧样片升级不改原值、保留手工编辑、避免重复升级、兼容原碰撞的检查。
- `npm run lint`：通过。
- `npm run assets:validate`：20 项通过。
- `npm run build`：包括正式资产构建后成功。最后收起对话路标与工具后再运行 Vite 生产构建，使用同批未修改的生成资产。
- 两个新模型均检查了四角度预览；浏览器中检查了实际人物正面与对话构图。

新资产源文件/优化后：园丁 246.82 / 59.68 KiB；留声柜 41.16 / 9.66 KiB。增加近景细节后，布景为 1.34 MiB / 310.72 KiB。全部生成资产 6.46 MiB，上一轮 6.30 MiB。

浏览器脚本 `check-coastal-study-browser.js` 增加新人物/道具加载、对话留出人物区域、对话键盘焦点检查，共 20 项。当前轮截图和报告使用 `output/playwright/coastal-refined-chrome/` 与 `coastal-refined-edge/`，保留上一轮的证据目录。

正式构建的 Chrome、Edge 各 20 项通过，均无未捕获页面错误。Edge 用实际 WASD / E 再次走通守园人、工坊、门，中途未传送；记录在精修目录的 `physical-walk.json`。新增花箱、盆栽和长椅未堵住主路线。

Chrome 的旧草稿升级专项 4 项通过：生成独立草稿、保留修改过的标题、保留工坊位置、刷新不重复升级（`output/refinement-upgrade.log`）。Edge 的 800×600 / 轻量模式对话专项 3 项通过：文字面板在视口内、直接切换的近景已检查、Escape 返回探索（`output/refinement-conversation.log`）。

本轮未重新运行第一轮的 HTTP 404 恢复专项，不将旧记录称为当前检查。通用资产错误边界和歌曲恢复代码本轮未修改。

最终生产 ExperienceRoot 脚本为 138.06 kB / gzip 41.80 kB，体验 CSS 为 6.40 / gzip 1.97 kB，物理场景入口为 69.04 / gzip 21.38 kB。Three 与物理运行库大小未变。构建日志：`output/refinement-build.log`（完整构建）、`output/refinement-final-build.log`（最后界面修整）。

在同一 RTX 4050 Laptop / 16 逻辑核心 / Windows / 1280×720 / DPR 1 的无头浏览器里，本轮采样记录 49 次绘制、85,562 三角形、GPU 占用估算下界约 32.46 MB。Chrome / Edge 的中位约 243.9 / 232.6 FPS，1% low 约 36.2 / 39.2 FPS，仍低于既定 40 FPS 目标。采样混有加载和交互、供电未知、未限速，继续不宣称受控性能验收通过。原始测量保存在两份 `report.json`。

## 仍有的差距

角色目前使用静态模型与既有轻微呼吸/倾身反馈，尚无手势、口型或完整表演。主角与园丁的面部和轮廓还可继续统一。离场门的科幻轮廓与花园仍有风格距离。受控前台浏览器的稳定帧率验收仍待进行；本轮无头性能数据只用于观察，不作为发布性能通过的证明。
