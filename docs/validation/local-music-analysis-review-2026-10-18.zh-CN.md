# 音乐分析：本轮复查与体验步骤

## 本轮目标

- 用户结果：用歌曲分段安排已有世界节点，并保留可修改、可恢复的项目。
- 当前阶段：Phase 3 的本地音乐分析小闭环，等待所有者体验验收。
- 最小路径：载入歌曲 → 分析 → 修改分段 → 放置已有节点 → 保存恢复。
- 范围外：BPM 工具接入、主歌/副歌自动识别、AI 生成、公开发布。
- 验收依据：现有 26 项浏览器检查，加上所有者对熟悉歌曲的试听判断。
- 影响：本轮只复查和补充验收说明；沿用本机分析、键盘输入、撤销和手动编辑。无新依赖、资源或付费调用。

## 亲自体验：一首熟悉的歌，约 5 分钟

本轮本机预览入口：<http://127.0.0.1:4173/>。预览服务运行期间可用。

1. 进入世界，载入一首你熟悉的 3–5 分钟歌曲。
2. 打开项目编辑器，找到“音乐分析与分段”，点击“分析当前歌曲”。
3. 挑一个明显变化处，点“定位试听”。这个按钮移动播放位置；暂停状态下，关闭编辑器后点播放试听。
4. 改一个段落名称和开始时间，保存；试一次撤销和重做。
5. 在上方选一个已有时间线节点，在目标段落点击“将所选节点移到这里”。关闭编辑器，从这个位置前后播放，观察世界变化。
6. 导出项目，再刷新页面。按提示恢复原歌曲，检查名称、边界和节点位置是否保留。

只需要记录三件事：

- 哪个按钮或步骤让你停下来想了很久？
- 分段建议能否帮你更快找到音乐变化？请指出一个具体时间点。
- 世界变化放到那个位置后，感觉是否合适？

建议以“歌曲时间 + 做了什么 + 期待什么 + 实际发生什么”反馈。所有者确认前，保持当前分析切片待验收状态。
