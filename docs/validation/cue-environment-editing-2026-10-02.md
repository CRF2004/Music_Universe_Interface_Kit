# 音乐事件环境参数：实现与验收

> 日期：2026-10-02；Phase 2，工具采纳计划 A3

## 结果与范围

打开 Project Editor，选择音乐事件，再选择 Environment action。可编辑天空颜色、地面颜色、雨量和光晕，点击 Apply environment action 提交。关闭编辑器，在音乐播放器跳到对应时间即可预览。

用户结果：通过界面修改音乐事件的画面效果，并保存、重新打开、导出。推进的阶段门槛为 Phase 2 的可编辑、可复现项目。最小交付包括四个参数、验证、撤销重做、自动保存和运行时重建。其他动作类型、增加/删除动作、任意 JSON 编辑和新依赖在本次范围之外。

颜色接受三位或六位十六进制值，如 #334b85；雨量为 0–1，光晕为 0–2。留空移除该事件的覆盖值，沿用前面的事件或运行时默认值。一次应用是一条可撤销记录。雾、星星、旁白和其他动作保持原值；切换项目隔离历史，刷新恢复保存项目并清空会话历史。

事件中有多个环境动作时可分别选择；没有环境动作时显示提示。输入错误保留已提交项目和重做分支。保存失败保留内存稿；导入验证失败保留当前项目。继续使用原有减少效果模式，雨和光晕可被关闭，作者设定值仍保存在项目中。

## 性能、无障碍、权利和限制

复用现有 React、项目 Store 和音乐时间线；未引入依赖、外部资产或服务。生产 ExperienceRoot 为 92.14 kB / gzip 26.10 kB，较拖拽完成时增加 5.31 / 1.34 kB。其余主要运行库体积保持原构建水平。

字段有可读标签、键盘焦点和范围提示，错误通过现有草稿状态区域播报；草稿恢复、减少效果和音乐控制继续使用已有路径。环境颜色使用文字输入，可通过键盘精确编辑。

环境 payload 的字段校验同时进入运行时校验器和 JSON Schema。雾密度为 0–1，星星为 0–1000 的整数，颜色限定十六进制；不支持的字段被拒绝。旧文件中的未校验值可能需要修正后再导入。项目结构与 schemaVersion 1 保持一致。

本次只交付有限环境动作检查器；Phase 2 整体验收仍待支持浏览器复测。下一步为 A4 创作流程验收，Edge 的本机启动问题仍需处理。
