# Childhood 短程试听与段落对齐

实现开始于 2026-10-18，最后浏览器复查于 2026-10-19（上海时间）。

- 用户结果：进入花园播放已下载的 Childhood，查看与曲目起伏对应的旅程段落。
- 当前阶段门槛：Phase 3 完整可玩的美术样片；本次是用户授权的 2:17 短程试听，不关闭产品 3–5 分钟目标或美术验收。
- 最小闭环：来源与使用说明复核 → 正式音频构建 → 独立试听草稿 → 七段时间线 → 开门、结尾、seek/replay。
- 范围外：拉伸/循环歌曲、通用音乐编辑器扩展、新故事、付费服务、部署发布。
- 验收：源文件 SHA-256、实际解码/时长、正式构建与预算、真实浏览器播放/段落跳转/结束/重播/回读；音乐审美与耳听段落验收留给实际试听，不将能量分析等同听感判断。
- 性能/无障碍/权利：沿用正式 Ogg / -16 LUFS 管线，界面显示署名；曲目页与作者使用说明随许可记录保存；可暂停、音量与轻量模式沿用。旧草稿保留。

## 量化依据与初版编排

原 MP3 解码成 16 kHz 单声道做既有 peak/RMS 分析，实际 PCM 137.0791875 秒。2 秒前后窗能量差检测得到约 88.2 秒与 128.1 秒的显著变化；4 秒窗显示 88–92 秒约 -21.4 dB，92–96 秒约 -16.4 dB，96–120 秒维持较高能量；124 秒后明显衰减。并不据此推断配器、人声或精确乐句。

编排为：0 晨光；22 树影；44 回声靠近；64 记忆生根；88.2 归途准备；96 开门；124.5 余音。前四段为人工叙事安排，后段参考实际能量变化。七个 cue 保留既有语义动作，使用曲内归一化位置随实际浏览器时长编译。

## 交付与回退

正式资产 `scott-buckley-childhood` 保留原始 MP3，生成 Ogg。使用 `LicenseRef-Scott-Buckley-Library` 记录原作者声明的 CC BY 4.0 与附带的官网使用说明；批准范围为带署名的项目内同步播放及对应音量处理，不包含独立音乐销售、音乐平台再发行或 Content ID 登记。许可快照位于 `assets/licenses/scott-buckley-childhood.snapshot.md`。

曲目分析保存在项目的既有 `track.analysis` 字段；不引入新 schema。章节按钮现在读取项目 cue 位置，手工修改时间后会跟随，缺失的章节不生成猜测跳转。

新建花园草稿采用 Childhood。旧花园使用 `?study=coastal&score=childhood-v1` 生成独立试听草稿：保留场景，换成新歌曲和本曲的七段编排；原稿和原编排仍在项目库中。已经是 Childhood 的草稿刷新保留手工改动，不反复创建副本。普通 Memory Journey 默认演示曲保持原选择。

播放前和播放控件均可展开“音乐署名”，查看作者、CC BY 4.0、官网/许可网址与音量处理说明。首次播放仍由进入按钮触发；上传本地曲目后的恢复、暂停、音量和轻量模式继续可用。

## 体积与性能观察

原 MP3 5.23 MiB → 生成 Ogg 2.96 MiB（3,098,930 字节），全部生成资产 9.59 MiB，仍保留旧曲以供原项目使用。ExperienceRoot 150.94 / gzip 49.11 kB，体验 CSS 6.65 / gzip 2.03 kB；主要运行库未变。

同一 Windows / RTX 4050 Laptop / 16 逻辑核心 / 1280×720 / DPR 1 无头观察：44 次绘制、88,030 三角形、GPU 估计下界约 32.83 MB。Chrome / Edge 最近采样的中位约 263.2 / 344.8 FPS，1% low 36.9 / 65.4 FPS。Chrome 低于既定 40 FPS 目标，且两次采样时刻不同、供电未知、加载与交互混合、未限速，不能比较为优化收益或宣布性能发布通过。实际传输约 3.86 MB，见两份 `report.json`。
