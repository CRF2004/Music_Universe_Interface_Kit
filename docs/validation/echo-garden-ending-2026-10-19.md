# 花园结尾与一键重走

- 用户结果：完成后看见归途场景，可留在余音或一键重走。
- 当前阶段门槛：Phase 3 完整 demo 的体验质量；音乐听感和视觉验收仍待用户判断。
- 最小闭环：送达记忆 → 结尾构图 → 从零播放、清空任务、回到出生点 → 再次交谈。
- 范围外：新故事、资产生成、通用编辑器、发布、扩大音乐编辑功能。
- 验收：浏览器结尾画面、键盘焦点、主动重走、自然结束后重走、重复操作、任务/音乐/人物复位、轻量模式与小窗口；单元测试、类型检查、正式构建。
- 性能/无障碍/权利：复用已授权资产和曲目；轻量模式直接切镜头；按钮可键盘操作，播放失败提供现有错误提示，留在余音不改进度。

## 完成行为

- 归途结尾使用专属镜头、右侧文案和音乐署名；可留在余音中保留完成状态。
- “再走一次”将歌曲归零并播放，重建时间线状态，清空任务与交互记录，人物回到出生点，镜头恢复探索角度。自然结束后也可重走，并再次与园丁交谈。
- 修复弹窗键盘焦点循环遗漏音乐署名 summary 的问题。Escape 可关闭结尾。
