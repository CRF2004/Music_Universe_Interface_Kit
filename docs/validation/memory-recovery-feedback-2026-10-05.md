## 候选核对与选择

核对 [Wawa VFX 官方仓库](https://github.com/wass08/wawa-vfx)的 React/vanilla 源码、包元数据与 MIT 许可。当前 React 源码通过 useFrame 将页面 clock 时间传给粒子 core；vanilla core 的 update(time?) 支持外部时间。Emitter 维护发射历史并使用随机采样。音乐 seek/replay 的确定重建仍需时钟适配、固定采样和发射历史重建。

本轮只有 24 个光点，现有 Three 实例渲染足够。选择本项目自制的无状态采样实现，暂不引入 Wawa 依赖；后续确有多种大型粒子效果需求时再评估 adapter。此次为源码/API 适配评估及现有渲染小样，不声称完成 Wawa 运行时帧率对照。第三方源码只存于忽略目录 output/tool-pilots/2026-10-05/wawa，不进入运行包。

组件使用播放存储中的实际 currentTime，每帧根据相同音乐时间直接算出全部光点位置，不累计 delta、不读取页面计时器。暂停后位置固定，向前或向后跳转直接重建；重播与曲目替换通过已有互动重置移除反馈。几何置于 Archive 视觉组内，移动建筑时沿当地球面一起移动。晶体和光点使用基本几何，无额外碰撞体。
