## 实践方案

继续使用记忆旅程的同一套互动与结尾。原创制作奶油色记忆工坊、青绿色屋顶、树丛、步道、街灯、小屋和远景观景塔。场景形成前景路径、中景建筑与远景轮廓。场景装饰合并为材质批次，并烘焙到 60 米球面。

制作入口：`scripts/generate-echo-garden.mjs`。模型为 `memory-atelier` 和 `coastal-garden`。工坊保持现有建筑的 10.4 × 5.2 × 14.2 米包络和碰撞契约；整体布景使用静态三角网格碰撞。来源和构建配置写入正式资产清单。

新增可选 `scene.environment.look = coastal-garden-v1`，由受校验的版本化美术套件控制灯光、地面材质和探索镜头。套件要求对应的已授权布景模型与 120 米直径球形地面。旧项目无此字段时继续使用现有默认显示。

样片入口为 `?study=coastal`。控制器在本地项目库恢复后，调用普通导入器创建独立草稿；刷新当前样片保留编辑结果。音乐和世界状态继续由现有时间线系统控制。界面提供实际播放、暂停、音量、段落跳转、操作帮助和编辑入口。

## 实践后的结论

现有运行时和资产管线可以承载一套经过人工设计的作品。当前“选模板和资产”的界面，还无法直接产出 Messenger 参考中的完成度。

| 制作环节 | 本次实际做法 | 当前搭建界面能否完成 |
|---|---|---|
| 完整故事、交互、音乐时间和结尾 | 复用 Memory Journey | 能，已有模板 |
| 角色/建筑/门的兼容选择与保存 | 现有 approved role catalog、校验、项目库 | 能，选择范围有限 |
| 工坊、树木、小屋、路灯、石径和构图 | 新写原创资产生成脚本，多轮画面修整 | 需要人工资产制作和代码 |
| 地面颜色、海岸、灯光、镜头比例 | 新增受校验的 `coastal-garden-v1` 美术套件 | 套件可保存；配置仍在代码中 |
| 开场排版、低干扰播放控件、中文叙事面板 | 新增样片界面与文案 | 需要人工设计和代码 |
| 单棵树/单间小屋的再摆放 | 当前烘焙进整套布景 GLB | 尚不支持界面内逐件编辑 |
| 成品一致性验收 | 亲自操作浏览器、检查开场/中段/结尾截图 | 仍需要人的视觉判断 |
